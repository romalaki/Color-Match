# Color-Match
Разработал простую казуальную игру, где игрок управляет корзиной, случайно изменяющей цвет и должен собирать падающие фигуры с соответствующим цветом, избегая фигур неподходящего цвета, на время.


Управление-пальцем водить по корзине, корзина плавно двигается за пальцем.
Интересные факты-я разработал сохранение прогресса при выходе из игры, так же обработчик кнопки Назад. В этом приложении использую Scriptable Objects и Zenject.
